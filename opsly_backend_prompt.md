## ENGINEERING PRINCIPLES (MANDATORY — apply everywhere)

1. **Separation of Concerns:** Strict three-layer architecture in every module:
   - `routers/` → API endpoints only (HTTP in/out). No business logic.
   - `services/` → All business logic. Calls repositories. No direct DB access.
   - `repositories/` → All SQLAlchemy queries. No business logic.

2. **Dependency Injection:** Use FastAPI `Depends()` for:
   - DB session: `get_db`
   - Current user: `get_current_user`
   - Permission checks: `require_role(["owner", "moderator"])`

3. **Pydantic V2 schemas:** Every request body and response model uses Pydantic V2. No bare dict responses. Use `model_config = ConfigDict(from_attributes=True)`.

4. **DRY:** Extract all reusable logic (pagination, audit logging, file upload) into shared utilities in `app/utils/` and `app/core/`.

5. **Immutable audit log:** Every write to critical tables (`tickets`, `inventory_items`, `attendance`, `tenders`) must write a corresponding row to the `audit_log` table using a SQLAlchemy event listener.

6. **Soft deletes:** No `DELETE` statements on any business entity. Use `is_deleted: bool = False`, `deleted_at: datetime`, `deleted_by: uuid`.

7. **Server-side timestamps only:** Never accept a `created_at` or event timestamp from the client. All timestamps are generated by the server (`datetime.utcnow()`).

8. **Idempotency keys:** All POST endpoints that create business records must accept an optional `X-Idempotency-Key` header and return the existing record if the key has been seen before (use Redis for key storage, 24h TTL).

9. **Consistent error responses:** All errors return `{ "status": int, "code": str, "detail": str | list }`. Create a custom exception handler.

10. **Type hints everywhere:** 100% type annotation coverage. Use `from __future__ import annotations`.
